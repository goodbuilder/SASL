# Simulation report archive

Files in this directory are historical experiment evidence. They may reference
method implementations, profile schemas, coordinate aliases, or commands that
were valid only for the producing revision.

The direct-Gazebo Origin-BBOX, ROI/silhouette, and Kalman tracking search tools
were retired on 2026-07-20. Their archived reports use the historical
stereo-center RDF contract and Ground Truth for offline fitting or evaluation.
They do not define the current PX4-only motion or public measurement contract.

Use the current Simulation code, repository documentation, and tests as the
runtime source of truth. Check out the recorded historical commit if an old
experiment must be reproduced.
