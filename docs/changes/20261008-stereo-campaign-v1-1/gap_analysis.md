## Reusable components

Generated-world camera optical pose handling and Gazebo pose diagnostics, the 25 m/0.1 m rig geometry and K/FOV settings, simulation epoch tracking, source-image timestamps, one-to-one pairer, source-stamped Gazebo GT, atomic pair recorder, debug rosbag topic list, PX4 local-NED command transport and existing hash/validity code are useful starting points. Each needs the v1.1 boundary checks above before its output counts as campaign evidence.

## Verification limits

This audit compares the checked-out source/configuration. It does not prove the installed ROS overlay matches source, an external PX4 build is compatible, actual YOLO weights exist, camera/GT topics reach specified rates, the drone mesh fits both images, any historic run is reusable, or any of the 39 runs completed. The active `simulation.env` is modified by pre-existing work; the analysis did not change it.
