# Subframe-Level Synchronization in Multi-Camera System Using Time-Calibrated Video

**Xiaoshi Zhou, Yanran Dai, Haidong Qin, Shunran Qiu, Xueyang Liu, Yujie Dai, Jing Li, Tao Yang.** *Sensors*, 24(21), 6975 (2024). [DOI and official full text](https://doi.org/10.3390/s24216975)

**Read status:** Publisher abstract and method summary checked; metadata verified against MDPI.

## Content checked

The paper records a time-calibrated video before the target scene, estimates each camera's local-time relation to a global reference, rewrites frame timestamps, and applies frame interpolation for subframe alignment. This is an offline video-content-based synchronization method rather than a clock oscillator characterization.

## Relation to this project

Related to [[Workstation - Camera clock drift]] and [[Seyfu 2025 - Consumer stereo synchronization]]. It offers a different mitigation path if the measured Workstation clock-rate gap is shown to affect stereo pairing.
