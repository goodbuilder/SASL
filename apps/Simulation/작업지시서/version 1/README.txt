패키지 사용 안내
작성일 2026-10-05 / 프로토콜 v1.1

v1.1 변경: RPY_IMU(roll/pitch/yaw 공동 추정)가 주 방법, YAW_ONLY가 비교 기준입니다.
카메라 XYZ는 RTK 측정 광심 좌표에 고정하며 위치를 교정하지 않습니다.
roll/pitch에는 유한한 카메라 IMU prior를 적용합니다. 두 방식은 같은 센서 관측을 사용합니다.
참 위치·참 roll/pitch 고정 조건은 YAW_IDEAL이라는 이상적 진단으로만 남깁니다.
39개 비행 ID·seed·경로는 v1.0과 동일합니다. 이 개정에 따른 추가 Gazebo 비행은 0회입니다.
주 센서오차는 카메라 IMU sigma=0.02deg, 카메라/드론 RTK sigma_xyz=(0.02,0.02,0.04)m입니다.
이 수치는 실장비 성능 보증이 아닌 모의 관측의 설계값입니다.

00_학생에게_보낼메시지.txt : 학생에게 보낼 짧은 전달문
01_학생용_실행지시서.pdf : 실행 순서와 체크리스트 중심 지시서
02_Codex_작업지시문.txt : 학생 컴퓨터 Codex에 붙여 넣을 독립적인 작업 지시문
03_experiment_spec.json : 수치·좌표계·저장·오류 처리 규격
04_run_manifest.json : 계획된39개 실행 ID와 seed
05_generate_reference.py : 좌표·시간 참조 생성과 기하 점검 도구. Gazebo 실행기가 아님
06_v1_1_변경사항.txt : 교정 대상·비교 기준 변경과 기존 데이터 재사용 안내
reference_generated/ : 이 패키지의 수치로 생성한6개 참조 경로와 기하 점검 결과
SHA256SUMS.txt : 파일 체크섬

참조 경로 재생성 (Python3 표준 라이브러리만 필요)
  python3 05_generate_reference.py --output-dir ./reference_generated

학생 컴퓨터의 기존 Gazebo/PX4/ROS 실행기는 별도로 조사·연결해야 합니다.
본 패키지는 학생 컴퓨터의39회 시뮬레이션을 실행한 결과가 아닙니다.
원래 대화의 '추가9회 선정경로'는 실행 전 고정할 수 있도록 P4로 구체화했습니다.
P4를 최적이라고 가정하지 않으며, V0 결과로 P4를 사후 변경하지 않습니다.
가감속5초는 순항5m/s와 함께 정의한 실행 사양입니다. 전체 평균속도5m/s라는 뜻이 아닙니다.
목표 위치오차 요구값은 아직 정해지지 않아 null이며, 임의의 논문 합격 성능을 만들지 않습니다.
