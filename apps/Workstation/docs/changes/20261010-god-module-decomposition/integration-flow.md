# Integration flow

UI command -> feature facade/adapter -> feature-owned state/service -> existing worker/device/storage -> immutable result/state -> presentation.
Frozen pair -> explicit method plan/geometry inputs -> application-lifetime workers -> original-generation commit owner -> recording ledger/store -> UI projection.
Close -> explicit feature resource inventory -> existing ordered lifecycle -> verified worker/thread/file cleanup.

At every handoff retain identifiers, frame/unit/time contracts and original owner leases. Compatibility names must not become a second resource/state owner.
