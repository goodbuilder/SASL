# Backend contract

Feature-owned state is authoritative. Core planners/geometry/projection services operate on explicit immutable inputs; no Qt widget or universal panel is passed to them. Recording native and primary owners collaborate through one admission ledger, preserving RLock, first-terminal identity, original row object/lease and bounded retry accounting.

Compatibility may expose old named methods/properties at the outer facade. Extracted components call their actual collaborators and do not recurse through panel._record_* or a universal __getattr__/__setattr__ bridge. Injection ports list their operations/data explicitly.

Workers, queues, timers and sockets retain one owner; lifecycle uses an explicit inventory when state leaves vars(panel). Existing Run service, deep immutable payloads and identity-guarded method recovery remain in use. Canonical numeric values/schema/hash bytes remain stable.
