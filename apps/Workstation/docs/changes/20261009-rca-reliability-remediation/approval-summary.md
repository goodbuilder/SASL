# 실행 범위와 승인 근거

사용자가 RCA 결과에 이어 “안전한 수정계획 ... 그 후 수정을 진행 ... 기대효과 ... 확인”을 명시적으로 요청했다. 이 문서는 해당 요청의 실행 계획이며 별도의 재승인을 요구하지 않는다.

수정: 깊은 스냅샷 불변성, 작동하는 CI/이식성 gate, 독립 Run 상태 소유권, 계산 상태 표시와 선택적 worker 복구, 현재 설명의 일관성. 수치/좌표/기록 스키마, 기존 관측 우선 시작/종료, 느린 계산의 무제한 실행, 앱 수명 worker 및 늦은 결과 귀속을 보존한다.

복구 버튼은 선택한 method의 현재 계산을 실패로 기록하고 worker를 교체한다. 이후 대기 작업은 계속한다. 일반 Stop은 기존처럼 늦은 계산을 취소하지 않는다.

효과는 변경 전 재현과 변경 후 회귀로 입증한다. 실장비 정밀도 또는 장시간 현장 인증을 이 소프트웨어 변경의 결과로 주장하지 않는다.
