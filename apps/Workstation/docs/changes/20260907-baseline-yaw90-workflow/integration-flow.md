# Integration Flow

Existing camera frame signals -> new display copies (no capture overlays). Existing visible workspace poll -> facade snapshot -> tables. Reverse draft -> explicit Apply/Save -> settings owner runtime guard -> original override -> optional existing persistence -> confirmed status. Save failure remains retryable and does not claim success.

Leave setup Method -> Alignment inspection_clear_requested(owner) -> main-window routing ->
Inspector.clear_selection(context, owner) -> clear only matching details and refresh normal
context. No setup snapshot is read while inactive. Viewport Resize -> coalesced owned QTimer ->
refit preview heights after Qt layout settles -> unchanged tables remain inside the viewport.
