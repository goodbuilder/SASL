# Slices

S1 Loader + shell: load native Qt5 .ui, insert custom views, retain dock object names and command registry.
S2 Stable workspaces: feature-specific forms with existing public widget references and signals; custom views inserted in explicit containers.
S3 Settings: native controls retain keys/defaults/data and guarded persistence.
S4 Integration: Designer edit/save/load evidence, isolated UI regression and real shell screenshots, shutdown and portability.

Independent feature owners may work concurrently in non-overlapping files; parent integrates and runs full regression. Record each completed/failed slice in verification.md. Do not call an empty wrapper a complete page conversion.
